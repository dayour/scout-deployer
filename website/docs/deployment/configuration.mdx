# Configuration

Scout Deployer loads configuration from environment variables and an optional `.env` file.
Copy `.env.template` to `.env`, then keep `.env` private.

```powershell
Copy-Item .env.template .env
notepad .env
```

## Precedence

1. Command-line parameters
2. Process environment variables
3. `.env`
4. Safe public example defaults

## Tenant and identity

| Variable | Purpose | Public example |
|---|---|---|
| `SCOUT_TENANT_NAME` | Friendly tenant name | `Contoso` |
| `SCOUT_TENANT_ID` | Entra directory ID | `00000000-0000-0000-0000-000000000000` |
| `SCOUT_DOMAIN` | Primary tenant domain | `contoso.com` |
| `SCOUT_DOMAIN_ALT` | Optional alternate domain | empty |
| `SCOUT_LICENSED_USER` | User with the required Copilot license | `admin@contoso.com` |
| `SCOUT_APP_CLIENT_ID` | Entra application/client ID | `11111111-1111-1111-1111-111111111111` |
| `SCOUT_APP_OBJECT_ID` | Entra application object ID | `22222222-2222-2222-2222-222222222222` |
| `SCOUT_APP_NAME` | App registration display name | `Scout` |

`SCOUT_APP_REG_ID` remains a compatibility alias for `SCOUT_APP_CLIENT_ID`.

## Fleet and credentials

| Variable | Purpose |
|---|---|
| `SCOUT_SYSTEM_NAME` | Friendly fleet name |
| `SCOUT_PRIMARY_NODE_IP` | Primary IP address or hostname |
| `SCOUT_PRIMARY_NODE_NAME` | Friendly primary node name |
| `SCOUT_ADDITIONAL_NODES` | Comma-separated IP addresses or hostnames |
| `SCOUT_TARGET_USER` | Remote local-administrator account |
| `SCOUT_SSH_KEY_PATH` | SSH private-key path |

## Installer and local assets

| Variable | Purpose |
|---|---|
| `SCOUT_VERSION` | Scout installer version |
| `SCOUT_INSTALLER_PATH` | Local installer path |
| `PUTTY_DIR` | Directory containing `plink.exe` and `pscp.exe` |
| `LOCAL_SKILLS_ROOT` | Skills source |
| `LOCAL_MEMORY_ROOT` | Memory source |
| `LOCAL_SESSION_ROOT` | Session-history source |
| `LOCAL_CONNECTORS_ROOT` | Connector manifests |
| `LOCAL_MCP_MANIFESTS_ROOT` | MCP manifests |
| `LOCAL_AUTOMATIONS_ROOT` | Automation assets |
| `LOCAL_EXTENSIONS_LIST` | VS Code extension list |
| `LOG_DIR` | Run-log directory |

## Inspect active configuration

```powershell
.\ScoutDeployer.ps1 -ShowConfig
```

Do not paste the output into issues or public logs without reviewing tenant, user, host,
and path values.

## Repository hygiene

The repository ignores:

- `.env` and `.env.*` except `.env.template`
- secret-specific files
- logs
- common private-key and certificate formats
- dependency and editor output
Use the [configuration schema](../reference/schemas#deployment-configuration-schema)
to validate generated configuration.
