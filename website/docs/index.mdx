## What Scout Deployer manages

Scout Deployer installs Microsoft Scout on remote Windows nodes over PuTTY/SSH and can
provision the supporting operator surface:

- Scout binary deployment and policy enablement
- Skills and connector manifests
- MCP server manifests and tool registration
- File-system and registry permissions
- Memory and session-history assets
- VS Code extensions
- Scheduled automations and runbooks

The broader architecture adds a typed Scout control plane, SDKs, an execution runtime,
swarm orchestration, MCP server/host integration, and a standalone CLI.

## Production principles

1. Keep tenant-specific values in `.env`, environment variables, or a secret manager.
2. Treat desktop identity as a public-client flow; never ship a client secret.
3. Validate the managed-policy source and key casing for each operating system.
4. Verify both sides of the Frontier gate: tenant/device policy and licensed user sign-in.
5. Keep control-plane contracts, SDK models, policy renderers, and MCP tools synchronized.
6. Run the verification checklist after every identity, policy, installer, or scope change.
