# Entra app registration

Scout desktop authentication uses one single-tenant Microsoft Entra app registration.
It is a public native client: it has no client secret and requests delegated permissions
as the signed-in user.

## Registration facts

| Setting | Value |
|---|---|
| Display name | `{{SCOUT_APP_NAME}}` |
| Application/client ID | `{{SCOUT_APP_CLIENT_ID}}` |
| Object ID | `{{SCOUT_APP_OBJECT_ID}}` |
| Directory/tenant ID | `{{SCOUT_TENANT_ID}}` |
| Tenant domain | `{{SCOUT_DOMAIN}}` |
| Supported account types | My organization only (`AzureADMyOrg`) |
| Client type | Public/native |
| Fallback public client | `true` |
| Client credentials | None |

## Why it is shaped this way

### Public client, no secret

A desktop application cannot keep a client secret confidential. Scout uses MSAL
interactive, device-code, and silent-refresh flows and ships no credentials.

### Deep link, not localhost

Windows and Linux use the custom protocol `ms-clawpilot://auth/callback`. Electron handles
the callback through its single-instance/deep-link integration. The registration does not
need an HTTP localhost reply URL.

### macOS broker redirects

The signed macOS build uses `msauth.com.microsoft.clawpilot://auth`. Unsigned and development
builds use `msauth.com.msauth.unsignedapp://auth`.

## Public-client redirect URIs

| URI | Platform | Source constant |
|---|---|---|
| `ms-clawpilot://auth/callback` | Windows and Linux | `DEEP_LINK_REDIRECT_URI` |
| `msauth.com.microsoft.clawpilot://auth` | macOS signed build | `MACOS_BROKER_REDIRECT_URI_SIGNED` |
| `msauth.com.msauth.unsignedapp://auth` | macOS unsigned/development | `MACOS_BROKER_REDIRECT_URI_UNSIGNED` |

## Runtime alignment

The registration must stay synchronized with:

- `BASE_SCOPES` and `FEATURE_SCOPES` in the MSAL provider
- deep-link constants
- Electron bundle identifiers
- packaged application authentication configuration

```ts
export const CLIENT_ID = "{{SCOUT_APP_CLIENT_ID}}";
export const TENANT_ID = "{{SCOUT_TENANT_ID}}";
export const AUTHORITY =
  `https://login.microsoftonline.com/${TENANT_ID}`;
```

The home-account filter uses the configured tenant ID. Changing tenants changes which
accounts are accepted as home accounts.

## Admin consent

Grant tenant-wide consent after reviewing the delegated scopes:

```powershell
az ad app permission admin-consent --id {{SCOUT_APP_CLIENT_ID}}
```

This action requires an appropriately privileged Entra role, such as Privileged Role
Administrator or Global Administrator.
