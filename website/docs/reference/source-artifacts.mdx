## Sanitization policy

The retained HTML and this wiki intentionally use tokens instead of live environment data:

```text
{{SCOUT_TENANT_NAME}}
{{SCOUT_TENANT_ID}}
{{SCOUT_DOMAIN}}
{{SCOUT_DOMAIN_ALT}}
{{SCOUT_LICENSED_USER}}
{{SCOUT_APP_NAME}}
{{SCOUT_APP_CLIENT_ID}}
{{SCOUT_APP_OBJECT_ID}}
{{GITHUB_ACCOUNT}}
```

Embedded tenant screenshots, transcripts, private endpoints, and encoded executable
payloads are excluded from the public artifacts.

## Maintenance rule

When implementation contracts change:

1. Update the canonical code/OpenAPI/schema source.
2. Update the relevant retained source artifact if it remains authoritative.
3. Update this Docusaurus page and downloadable schema.
4. Build with broken-link checks enabled.
5. Re-run the sensitive-value scan before publication.
